M1 scope

Implemented in M1

  • DNS forwarding
    UDP and TCP, dual-stack IPv4/IPv6 listener, DNSSEC transparent proxy (DO bit forwarding)
  • Domain filtering
    NXDOMAIN / NULL / NODATA block policies, per-blocklist policy override, global default policy, subdomain blocking, wildcard entries
  • Allowlist
    Overrides blocklist, wildcard entries, remove
  • Local DNS entries
    A, AAAA, CNAME — priority over upstream and blocklist
  • DNS cache
    TTL-based caching, transparent to clients
  • Query log
    Recording, filtering by client/outcome, configurable retention
  • Config import/export
    Atomic import, credential-safe export, full round-trip
  • Basic auth
    First-run setup, password change, DNS unaffected by auth
  • Static binary
    CGO_ENABLED=0, Alpine-compatible musl binary
  • REST management API
    All management operations via HTTP API

Not implemented in M1

  • Multi-node clustering / Raft consensus (M2)
  • Parental controls / per-client profiles (M3)
  • DoH/DoT server (M4)
  • DHCP integration (M3.6)
  • Web UI SPA (M2.6)

Limitations

  • Single-node only — no replication or leader election
  • Query log raw data is per-node (cluster aggregation added in M2)
  • No Kubernetes / container orchestration support
