M12 scope

Implemented in M12

  • Cluster join via web UI (leader side)
    "Generate join token" button on the Cluster page calls POST /api/v1/cluster/tokens and displays token, leader_address, and expires_at with a Copy button.
  • Cluster join via web UI (follower side)
    POST /api/v1/node/join-cluster parses token + leader_address, calls ResetRaftForJoin(), and posts to the leader's join endpoint. UI panel disappears once mode becomes cluster. Returns 409 if already a member.
  • Config backup download
    GET /api/v1/config/export returns a .tar.gz archive with all config YAML. Admin credentials (password_hash) are absent — enforced by a separate exportShape struct.
  • Config backup restore
    POST /api/v1/config/import accepts a multipart archive, merges config atomically, preserves current node's admin credentials.

Not implemented in M12

  • Cluster leave / node removal via web UI (use DELETE /api/v1/cluster/nodes/{id} directly)
  • Scheduled or automatic backups — manual download only
  • Backup encryption — archive is plaintext tar.gz
  • Merge / diff between two backup archives

Known limitations

  • Join flow requires follower's Raft listener address to be reachable from the leader at AddVoter time
  • ResetRaftForJoin is irreversible once called; network failure after the call leaves node with no Raft state (auto-rebootstraps as single-node)

Retrospective note

M12 — Cluster Join via Web UI + Config Backup eliminated the two most common operator pain-points: needing SSH to grow a cluster, and needing SSH to back up or migrate configuration. The join flow's trickiest part was ResetRaftForJoin: it must be irreversible (Raft cannot be safely rewound) while still being safe to retry at the API level. The accepted trade-off is that a network failure mid-join leaves the follower without Raft state, but it auto-rebootstraps cleanly. The config export deliberately uses a separate exportShape struct rather than struct tags to omit credentials — struct-level omitempty is not supported by yaml.v3, so field omission by type composition was the only safe approach.
