M13 scope

Implemented in M13

  • Global pause — POST/GET/DELETE /api/v1/filtering/pause
    Suspends DNS filtering for all clients cluster-wide for a bounded duration. State replicated via Raft; survives node restart. Re-POSTing while active resets the timer.
  • Per-profile pause — POST/GET/DELETE /api/v1/profiles/{id}/pause
    Suspends filtering only for clients matched by the target profile. Other profiles remain fully enforced. Multiple profiles can be paused simultaneously with independent timers.
  • Ceiling enforcement — filtering.pause_max_seconds
    Configurable maximum pause duration (default 86400 s). Requests exceeding the ceiling are rejected with HTTP 400. Setting the ceiling to 0 disables the feature entirely for all scopes.
  • Profile-selection pause — profile_ids field on POST /api/v1/filtering/pause
    A global pause request can target specific profile IDs; only those profiles have filtering suspended. Rejects unknown profile IDs with HTTP 400. GET returns the active profile_ids list.
  • Query log annotation — pause_active field
    Every DNS query resolved during a pause (global or per-profile) is logged with pause_active: true so operators can audit traffic during the suspension window.

Not implemented in M13

  • Per-client granularity (pause applies to the whole profile, not individual IPs)
  • Scheduled or recurring pauses (always a one-shot deadline)
  • Notifications when a pause starts or expires
  • UI controls (pause management is API-only; web dashboard is read-only)

Limitations

  • pause_max_seconds = 0 disables the feature for all scopes; no per-profile opt-in when globally disabled
  • Clock skew between cluster nodes can cause a sub-second discrepancy in when the pause is enforced on each node (normal for distributed systems)
