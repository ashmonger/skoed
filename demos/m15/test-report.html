M15-A — Alt-Svc header for DoH/HTTP3 upgrade

When doh3_port > 0, every DoH (HTTP/2) response now includes Alt-Svc: h3=":<doh3_port>"; ma=86400. Firefox and Chrome auto-upgrade to HTTP/3 (QUIC) after the first H2 response. When doh3_port = 0 (the default), no header is set.

keepalived health-check script

The script at deploy/keepalived/skoed-health.sh is pushed to /etc/keepalived/ on each node during cluster provisioning. keepalived calls it every 2 seconds.

Script behaviour

Endpoint GET /api/v1/health
Host 127.0.0.1 (configurable)
Timeout 3 s
Exit 0 when {"status":"ok"}
Exit 1 when any other body, non-200, or curl fails
curl missing exits 1 immediately (fast-fail)
weight −20 (priority drops below all healthy peers)

Priority math on failure

When CT301's skoed is down, the track script exits 1. keepalived subtracts weight=20 from the effective priority:
CT301 effective: 101 − 20 = 81
CT302 effective: 100 − 0 = 100 ← winner
CT303 effective: 99 − 0 = 99
CT302 wins the election and the VIP moves to 10.0.0.12/eth0.

api_address requirement

skoed must bind its API on all interfaces, not a specific node IP:
node:
  raft_address: 10.0.0.11:7000
  api_address: 0.0.0.0:8080
When keepalived assigns the VIP (10.0.0.10) to eth0, skoed automatically serves traffic on that address because it listens on all interfaces. Inter-node forwarding still uses raft_address (node's own IP).
