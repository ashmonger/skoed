Binary Swap Flow

Steps ①–⑤ are inside upgrade.Swap() in internal/upgrade/swapper.go. Step ⑥ is in the handler (UpgradeStart): write 202, then schedule os.Exit(0) after 200 ms so systemd/OpenRC restarts with the new binary.

Key format: runtime.GOOS + "_" + runtime.GOARCH. If the feed omits assets or lacks the current arch, POST /upgrade/start returns 422.

Bug Fixed — Test Suite Binary Overwrite

Root cause

SymptomAll ARP/DHCP tests fail with 90 s timeout after upgrade tests run
Causeupgrade.Swap() replaces apps/skoed/skoed with the fake sentinel shell script
Whyos.Executable() in the subprocess resolves to the binary path; os.Rename overwrites it
AffectedTestUpgradeBinarySwap, TestUpgradeStartRecordedInAudit, TestUpgradeStartForwardedToLeader

Fix

Handler changeCheck SKOED_TEST_SWAP_DEST; if set, redirect exePath to that value
Test changeAll 3 tests set SKOED_TEST_SWAP_DEST=t.TempDir()/skoed_swapped
VerificationTestUpgradeBinarySwap reads the temp file and checks sentinel bytes match
Production pathUnaffected — SKOED_TEST_SWAP_DEST is never set in production; real exe path used
