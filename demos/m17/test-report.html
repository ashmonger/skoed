M17 scope

Implemented in M17

  • GET /api/v1/schedules/{id}/bindings
    List bindings for a schedule — returns an array of {schedule_id, profile_id, blocklist_id} objects. Returns 404 when the schedule does not exist.
  • Shadow YAML includes schedules + schedule_bindings
    After any schedule or binding mutation, the ShadowWriter writes <data_dir>/config.yaml with schedules: and schedule_bindings: sections. Replicated via Raft — all followers converge within ~1 s.

Not implemented in M17

  • UI for schedule binding management (schedule builder handles windows only)
  • Bulk-binding multiple (profile, blocklist) pairs in a single request
  • Binding overlap / conflict validation

Limitations

  • GET /api/v1/schedules/{id}/bindings is served from local node state — sub-second staleness window on followers immediately after a mutation (normal Raft eventual consistency)
  • schedule_bindings: is omitted from the shadow YAML when the list is empty (uses omitempty)
