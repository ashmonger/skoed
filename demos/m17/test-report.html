M17 scope

Implemented in M17

  • GET /api/v1/schedules/{id}/bindings
    List bindings for a schedule — returns an array of {schedule_id, profile_id, blocklist_id} objects. Returns 404 with {"error":"schedule not found"} when schedule does not exist.
  • GET /api/v1/config/export
    Downloads a tar.gz archive (Content-Disposition: attachment; filename="skoed-config.tar.gz") containing the full config.yaml of the cluster. Returns HTTP 200 with valid gzip. Requires Bearer token.
  • POST /api/v1/config/import
    Accepts a multipart/form-data POST with field name archive containing the tar.gz. Returns HTTP 200 {"status":"imported"} on success. Restores config and replicates via Raft.
  • Shadow YAML includes schedules + schedule_bindings
    After any schedule or binding mutation, <data_dir>/config.yaml is written with schedules: and schedule_bindings: sections. Replicated via Raft — followers converge within ~1s.

Not in M17 scope

  • UI for schedule binding management (API only in M17)
  • Bulk-binding multiple (profile, blocklist) pairs in a single request
  • Binding overlap / conflict validation
  • Config import via raw body (requires multipart/form-data with field archive)

Limitations

  • GET /api/v1/schedules/{id}/bindings is served from local node state — sub-second staleness window on followers immediately after a mutation (normal Raft eventual consistency)
  • schedule_bindings: is omitted from the shadow YAML when the list is empty (uses omitempty)
  • DNS listening only active on nodes explicitly configured with dns.listen.port != 0 (node-1 in this cluster)

Config export / import detail

Export: GET /api/v1/config/export
wget -q -O /tmp/test-export.tar.gz \ --header="Authorization: Bearer <token>" \ http://<NODE>:8080/api/v1/config/export # Response headers: # HTTP/1.1 200 OK # Content-Disposition: attachment; filename="skoed-config.tar.gz" # Content-Type: application/gzip # Content-Length: 1075 # Archive contains: config.yaml (full cluster config with schedules + bindings)
Import: POST /api/v1/config/import (multipart/form-data, field name: archive)
python3 -c " import urllib.request, io boundary = 'FormBoundary7MA4YWxkTrZu0gW' body = io.BytesIO() body.write(('--' + boundary + '\r\n').encode()) body.write(b'Content-Disposition: form-data; name=\"archive\"; filename=\"skoed-config.tar.gz\"\r\n') body.write(b'Content-Type: application/gzip\r\n\r\n') body.write(open('/tmp/test-export.tar.gz','rb').read()) body.write(('\r\n--' + boundary + '--\r\n').encode()) req = urllib.request.Request( 'http://<NODE>:8080/api/v1/config/import', data=body.getvalue(), headers={'Authorization': 'Bearer <token>', 'Content-Type': 'multipart/form-data; boundary=' + boundary}, method='POST') resp = urllib.request.urlopen(req) print(resp.status, resp.read().decode()) # 200 {\"status\":\"imported\"}"

Note: field name must be archive (not file). Content-Type must be multipart/form-data with correct boundary.
