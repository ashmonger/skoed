M2 scope

Implemented
  • Raft + bbolt FSM — hashicorp/raft replicated state machine
  • Single-node bootstrap — zero-config, defaults to single-node Raft cluster
  • Join token flow — single-use, sha256-hashed, 15-min TTL, leader-validated
  • Cluster membership management — AddVoter on join, RemoveServer on remove
  • Follower → leader write forwarding — every mutating endpoint
  • Cluster status API — /cluster/self, /cluster/status, /cluster/health
  • Automatic Raft leader election — on leader loss
  • Manual leadership transfer — POST /cluster/leadership/transfer
  • Cluster-wide query-log fan-out — /cluster/query-log
  • Shadow YAML write-through — debounced, atomic-rename after each Raft commit
  • M1 backward compat — auto-migrates M1-format config on first boot
Not implemented
  • Web UI for cluster topology (API-only)
  • Helm chart / Kubernetes DaemonSet (deferred to M2.5)
  • node.advertise_address separate from node.api_address
  • Per-client filtering / parental control (deferred to M3)
Known limitations
  • node.api_address used for both binding and advertising — must be a resolvable hostname, not 0.0.0.0
  • Aggregate flush lags up to 1 min on low-traffic clusters
  • Cluster secret replicated via Raft — harden with mTLS at network layer in production

Retrospective note

M2 delivered the full Raft-based clustering foundation. 103 acceptance tests green (58 M1 + 45 M2). 15 scenarios exercised in the Docker demo: single-node bootstrap, token issuance, 2-node and 3-node enrollment, leader write replication, follower write forwarding, two-client DNS check, cluster-wide stats fan-out, raw query-log fan-out, leadership transfer, node removal, minority partition, recovery, and shadow YAML output. Key learning: node.api_address must be a hostname reachable by peers, not 0.0.0.0:8080. Documented as backlog item for M2.1 (split api_address from a new api_advertise_address).
⚠ Sanitized report. Infrastructure details (hostnames, IP addresses) have been sanitized. Node IPs are shown as 10.x.x.x. All test results and behavioral outcomes are unmodified.
