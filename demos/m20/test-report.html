Implemented Features

Token Scoping

readwritecluster:admin APIToken.Scopes []string with RequireScope() middleware. Default tokens get ["read","write"]. The cluster:admin scope gates cert rotation.

CertCache — mTLS Hot-Reload

atomic.Pointer[certBundle] in the Raft TLS layer. Update() swaps the bundle atomically; GetCertificate/GetConfigForClient hooks serve new certs on next TLS handshake without dropping existing Raft connections.

OpCertRotation Raft Command

New FSM command distributes CertRotationPayload{CACertPEM, Nodes map[string]NodeCerts} to all cluster members. Applied by applyCertRotation(): writes certs to disk via MtlsPaths, calls cc.Update() for live reload.

API Endpoints

GET /api/v1/cluster/certs/status — CA + per-node expiry, any node, no forwarding.
POST /api/v1/cluster/certs/rotate — generates fresh CA + leaf certs, distributes via Raft, hot-swaps TLS. Requires cluster:admin. Returns 202.
