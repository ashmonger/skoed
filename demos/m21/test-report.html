Implementation

dns.dnssec_mode config field

Added to DNSConfig struct (config/config.go). Default "transparent".
PATCH /api/v1/settings {"dns":{"dnssec_mode":"validate"}} validates and applies immediately. rebuildDNS=true on change — DNS handler rebuilt with new config atomically.

classifyDNSSEC() in dns/handler.go

Called after upstream resolution in validate mode. Sets DO bit on outgoing query copy. Inspects resp.AuthenticatedData and RRSIG presence in resp.Answer. Returns (status string, out *dns.Msg) — replaces response with SERVFAIL when bogus.

dnssec_status in query log

Entry.DnssecStatus string field added to internal/log/query.go. queryLogEntry.DnssecStatus field exposed in GET /api/v1/query-log handler. Omitted from JSON when empty (transparent mode or non-forwarded outcomes).
