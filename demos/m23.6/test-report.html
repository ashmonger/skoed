What was validated (Proxmox 3-node LXC cluster)

  • Dedicated DHCP page: /dashboard/dhcp with its own navbar entry under System. Full pool config, enable/disable toggle, static assignments CRUD, live lease table with 10s auto-refresh.
  • Leader-forward proxy: DhcpLeases and DhcpServerStatus handlers forward reads from followers to the leader so every node shows complete lease data. Confirmed: all 3 nodes returned identical lease counts under load.
  • Static assignments: POST to /api/v1/dhcp/static-assignments; DELETE with raw MAC colons in path (chi router preserves them; encodeURIComponent is NOT used).
  • Shadow YAML extended: shadow_yaml.go now persists dhcp_server section including static_assignments. Full cluster cold-start survives without manual re-config.
  • Raft failover continuity: Leader stopped mid-test; new leader elected in 3.6 seconds; DHCP service resumed on new leader; post-failover new client received a lease.
  • API performance: 3ms average for /dhcp/leases across 30 concurrent requests to all 3 nodes with 51 active leases in pool.
