M3.5 scope

Implemented
  • Per-client DoH probe detection — GET /api/v1/clients/{ip}/doh-status; rolling 1-hour window; provider inference (Cloudflare, Google, Quad9, AdGuard, OpenDNS, NextDNS, ControlD)
  • Dashboard alert — top-5 clients with blocked DoH probes, auto-refreshes every 60s
  • Firewall rule generator — GET /api/v1/firewall-rules; iptables, nftables, MikroTik, OPNsense, UniFi; subnet/profile/all scopes
  • DoH resolver IP database — GET /api/v1/doh-resolvers; curated snapshot with leader-only scheduled daily refresh; replicated via Raft
  • Web UI "Copy rules" buttons — platform tabset on Clients and Stats pages
Not implemented (UoR carve-out)
  • ISC dhcpd lease file connector (EOL)
  • DHCPv6 support
  • Auto-remediation on DoH detection (alert-only)
  • "Closing the DoH gap" guide documentation
Limitations
  • DoH status endpoint is sourced from local query log only — no Raft round-trip, no cluster fan-out
  • Rolling 1-hour window driven by filter.Now(); sub-second staleness on followers immediately after a probe
