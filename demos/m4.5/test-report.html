M4.5 scope

Implemented in M4.5

  • Swagger UI bundled at /api/docs
    Interactive API documentation browser served as embedded assets
  • OpenAPI YAML at /api/v1/openapi.yaml
    Full OpenAPI 3.0 spec served as downloadable YAML
  • Assets served correctly
    JS, CSS, and other Swagger UI assets resolved relative to /api/docs
  • Disable-by-config option
    Set api_docs: disabled to hide the docs endpoint entirely
  • Browser auth honored
    Docs endpoint respects the same auth as the management API

Not implemented in M4.5

  • HTTPS management API (M4.6)
  • Try-it-out authentication pre-fill (manual token entry required)
  • Per-endpoint request examples in OpenAPI spec

Limitations

  • OpenAPI spec does not include endpoints added after M4.5 until spec is updated
  • Swagger UI version is bundled at build time; updates require a new binary
