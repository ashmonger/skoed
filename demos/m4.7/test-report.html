M4.7 scope

Implemented in M4.7

  • Cache stats endpoint
    GET /api/v1/cache returns hit count, miss count, size, entry count — auth required
  • Purge entire cache
    DELETE /api/v1/cache flushes all cached DNS responses immediately
  • Purge single domain
    DELETE /api/v1/cache/{domain} removes cached entry for one domain
  • Cache survives config change
    Cache is not flushed when non-upstream config changes are applied
  • Cache invalidated on allowlist add
    Adding a domain to the allowlist flushes that domain's cache entry to apply immediately
  • Auth required for all cache operations
    Unauthenticated requests return 401

Not implemented in M4.7

  • Per-domain cache TTL override (future)
  • Cluster-wide cache purge (purge is per-node only)
  • Cache warmup from external source

Limitations

  • Cache purge is per-node; cluster-wide purge requires calling each node individually
  • Cache stats are in-memory only; not persisted across restarts
