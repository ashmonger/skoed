Milestone Scope

Implemented
  • Lease origin tagging — http_json connector honours the origin wire field; maps to dhcp_static / dhcp_dynamic / router_advertised / manual_admin with confidence; blank field defaults safely to dhcp_dynamic/unknown
  • DHCPv6 lease parsing — ip6leases.conf parser; IPv6-only clients appear in /api/v1/clients; dual-stack clients merged; legacy v4-only shape unchanged
  • Raft-replicated lease cache — leader polls DHCP; snapshot replicated through Raft; followers serve /api/v1/leases from local bbolt replica without extra polling
  • ARP/NDP cross-check — rtnetlink detects IP-to-MAC mismatches between DHCP and kernel; SKOED_TEST_ARP_TABLE injects fake table in tests; degrades gracefully without NET_ADMIN
  • block_dynamic_clients profile rule — matches clients with origin=dhcp_dynamic and confidence=high; unknown origin excluded from matching
Not Implemented
  • Active mitigation — detect-only; no automated enforcement beyond profile matching
  • DHCP failover protocol awareness — both peers treated as equivalent sources
  • block_dynamic_clients on default profile — rejected with HTTP 400 to prevent lockout
  • DHCPv6 over http_json — http_json connector is IPv4-only
Limitations
  • ARP cross-check requires NET_ADMIN; degrades gracefully without it
  • origin_confidence=unknown clients excluded from block_dynamic_clients to avoid false positives

Retrospective

M6.5 adds Layer-3 anti-spoofing by cross-checking DHCP leases against the kernel ARP/NDP table, replicates the full lease cache via Raft so followers can serve consistent data without polling, extends lease parsing to DHCPv6, and tags each lease with its origin (static reservation vs dynamic assignment). The block_dynamic_clients profile rule enables coarse enforcement from origin metadata.
