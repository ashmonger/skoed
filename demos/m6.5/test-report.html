M6.5 Scope — Implemented

  • Lease origin tagging — dhcp_static / dhcp_dynamic / router_advertised / manual_admin (4 origin types); Kea reservations, dnsmasq dhcp-host config, HTTP JSON wire field, Prometheus gauges.
  • DHCPv6 lease parsing — ip6leases.conf (Kea lease6), dnsmasq lease6 file, dual-stack merge, per-v6-client lookup, profile matching unchanged, clients page V6 column.
  • Raft-replicated lease cache — leader-only polling, followers serve from bbolt replica, lease endpoint, source endpoint reports leader, failover resumes polling, no double-poll on transition, 503 when cluster empty, anomalies match leader, follower write forwarded, Raft log not amplified, stale follower catch-up, last_poll_unix advances, source unreachable keeps last good.
  • ARP/NDP cross-check via rtnetlink — ARP state agrees with lease, MAC mismatch flags anomaly, NDP MAC mismatch flags anomaly, ghost lease detection, fresh lease grace period, after grace period flagged, graceful degradation without NET_ADMIN, unknown IP 404, anomalies list includes new kinds, sweep cadence best-effort.

  • Push alerts for MAC spoofing detection
  • IPv6-only DHCP deployment support (dual-stack only)
