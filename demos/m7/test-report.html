Milestone Scope

Implemented
  • Bearer token authentication — Authorization: Bearer skoed_<48hex> accepted on all management API endpoints
  • Token CRUD via cluster API — mint (POST /api/v1/tokens), list without raw value, patch label/expiry, revoke (DELETE /api/v1/tokens/{id})
  • Scope enforcement — read scope blocks write mutations (HTTP 403); write allows mutations; cluster:admin required to mint and revoke
  • Audit log actor — Bearer calls log actor: "token:tok_<id>"; Basic Auth logs actor: "user:admin"
  • Raft-replicated revocation — revocation propagated via Raft; revoked token returns 401 on all cluster nodes
  • Token expiry — optional TTL; expired tokens return 401; tokens without expiry never expire
Not Implemented
  • Web UI token-management page — deferred to a UI sprint
  • last_used_at update on each request — field stored but not updated on use
  • Migration guide (Basic Auth to Bearer) — deferred to M8.1 docs
Limitations
  • Basic Auth continues to work as deprecated transition path
  • last_used_at field is always null in this milestone
  • In-flight requests past lookupAPIToken complete even after revocation
