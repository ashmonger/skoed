M8 Scope

Implemented ✓ Delivered

  • DoH3 (HTTP/3 over QUIC, RFC 9230) — disabled by default, independent enable via doh3_port, server listens and applies full filter pipeline, Alt-Svc header advertised when enabled, Alt-Svc absent when disabled
  • DNSCrypt v2 (ameshkov/dnscrypt) — disabled by default, independent enable via dnscrypt_port, server listens and applies filter, stamp published in GET /api/v1/settings, keypair generated and replicated via Raft
  • DNSCrypt keypair Raft replication — key generated on first boot, replicated to all nodes, consistent sdns:// stamp across cluster
  • Full filter pipeline — applies to both DoH3 and DNSCrypt transports (same blocklist logic as DNS/DoH)

Not Implemented Out of scope

  • DoH3 / DNSCrypt web UI configuration panel
  • DNSCrypt key rotation via API
  • Relay / anonymized relay support for DNSCrypt
  • QUIC connection migration / 0-RTT
