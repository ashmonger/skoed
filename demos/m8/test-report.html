Milestone Scope

Implemented
  • DoH3 (HTTP/3 over QUIC, RFC 9230) — doh3_port in node YAML; same miekg/dns handler pipeline; TLS 1.3 minimum; transport tagged "doh3" in query log; graceful shutdown on SIGTERM
  • DNSCrypt v2 server — dnscrypt_port in node YAML; UDP listener with XSalsa20Poly1305; full filter pipeline via ameshkov/dnscrypt bridge
  • Raft keypair replication — leader generates keypair within 30s of election; replicated via CmdDNSCryptKeysSet; configurable cert TTL; leader auto-rotates when TTL < 10%
  • dnscrypt_stamp in settings — GET /api/v1/settings returns sdns://… URI once keys are available
  • Independent enable/disable — DoH3 and DNSCrypt each controlled by port knob; neither active by default
Not Implemented
  • Web UI page for DNSCrypt stamp / DoH3 address display
  • TCP fallback for DNSCrypt — UDP only in this milestone
  • Key rotation trigger via API — leader-only automated rotation
Limitations
  • DNSCrypt cipher is XSalsa20Poly1305 only; XChacha20Poly1305 not yet configurable
  • No IP filtering on DNSCrypt — all source IPs accepted, consistent with other transport trust model

Retrospective

M8 extends skoed's DNS transport surface with HTTP/3 (QUIC) and DNSCrypt v2. Both transports plug into the existing miekg/dns handler pipeline so blocklists, allowlists, SafeSearch, and query logging apply uniformly. The DNSCrypt keypair is generated by the Raft leader and replicated to all nodes so each node presents an identical stamp to clients. Each transport can be enabled or disabled independently via its port knob.
