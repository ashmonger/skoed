M9 Scope

Implemented
  • SkoedCluster CRD (skoed.io/v1alpha1): schema, printer columns, registered in cluster
  • SkoedNode CRD: per-node configuration resource
  • Operator Helm chart: deploy/helm/skoed-operator/
  • controller-runtime v0.19.0 reconciliation loop
  • StatefulSet provisioning with init container writing node.yaml
  • Per-pod PVC via volumeClaimTemplates (data survives pod restart)
  • Scale up: new SkoedNode resources trigger auto-enroll
  • Scale down: graceful removal + leadership transfer before termination
  • Status conditions: Ready and Quorum (with failure states)
  • ACME cert rotation trigger via annotation
  • Helm fallback: existing bare-metal/LXC deployments unaffected
Not Implemented
  • Web UI for operator status / cluster management
  • Multi-namespace support
  • Automatic rolling upgrade via operator
  • Cross-cluster federation
